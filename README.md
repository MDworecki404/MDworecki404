## About

I'm a surveyor by training and a frontend developer by trade. At [infoSolutions](https://info-solutions.pl/) I work on WebGIS software in TypeScript and Vue. On my own time I build 3D web maps with CesiumJS, mostly from Polish open data (GUGiK, BDOT10k).

Cesium Certified Developer · UAS A1/A3 drone operator · MSc Eng. in Geodesy and Cartography, Wrocław University of Environmental and Life Sciences · Based in Wrocław

Currently learning Svelte 5, Angular and Docker.

## Projects

| Project | Description | Stack |
|---|---|---|
| [**UP.route**](https://dworecki.dev/projects/up-route) | 3D geoportal that finds routes between buildings on the UPWr campus on foot, by bike and by car. My master's thesis. | Vue 3, TypeScript, CesiumJS, Pinia, FME |
| [**GIS of Gothic**](https://dworecki.dev/projects/gisofgothic) | 3D encyclopedia of the Gothic world: find an item or a character and see where it lies, who carries it and where someone is at a given time of day. | SvelteKit, TypeScript, CesiumJS |
| [**Geoserwis: Dolina Jezierzycy**](https://dworecki.dev/projects/geoservice-dj) | Web map of the Jezierzyca Valley Landscape Park with bike and walking routes. My engineer's thesis and first GIS project. | Vue 3, Leaflet, QGIS |

More at [dworecki.dev/projects](https://dworecki.dev/projects).
